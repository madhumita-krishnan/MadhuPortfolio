Design system

Stack

Swiss-editorial banking. One signal red on warm paper, black ink, hairline borders, sharp corners everywhere. Color is reserved for meaning: red for actions and the current moment, category colors only for data.

Screens

The exported frames these tokens were sampled from.

Provenance: every color was sampled pixel-for-pixel from the lossless PNG exports in stack screens/screens-no-bezel (2× of the 390 pt frame), so the hex values are exact. Type sizes were measured from glyph heights in the same exports (±1 px). The typeface renders as Helvetica Neue. Components on this page are CSS reconstructions of the shipped screens.
