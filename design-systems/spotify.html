Design system

Spotify Mix

A redesign that lives inside Spotify's dark Encore language: near-black surfaces, white ink, one green for every action — plus a small extension layer this project adds: Camelot key badges, bpm chips, and an ember warning treatment for hard blends.

Screens

The exported frames these tokens were sampled from.

Provenance: colors sampled pixel-for-pixel from the lossless PNG exports in Project 1 Spotify/screens — exact except --text-secondary (*), which is too thin to sample flat at export resolution and uses Spotify's Encore standard value, visually matched. Note the action green here is #55D05E, not Spotify's marketing #1ED760 — that is what the design file actually uses. Type sizes are measured approximations against the 393 pt frame. Components are CSS reconstructions of the screens.
